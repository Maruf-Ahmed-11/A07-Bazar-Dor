# 🛒 বাজার দর (BazarDor)

A modern, responsive web application designed to track the daily market prices of essential commodities in Bangladesh. Stay updated with the latest price trends, market-specific rates, and price fluctuations for everyday items like rice, vegetables, meat, and spices.

## 🚀 Technologies Used

*   **Framework:** Next.js 15 (App Router)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS, DaisyUI
*   **Authentication:** Better-Auth (Google, GitHub, and Email/Password)
*   **Database:** MongoDB
*   **Data Source:** Custom External API

## ✨ 5 Key Features

1.  **📊 Live Price Tracking & Trends:** View daily updated prices of essential goods, including visual percentage indicators showing price increases, decreases, or flat rates compared to the previous day.
2.  **🛍️ Dynamic Product Pages:** Explore detailed views for individual items featuring minimum, maximum, and average price calculations across various regional markets.
3.  **↕️ Category Sorting Controls:** Easily filter and sort commodities within specific categories by "Default", "Price: Low to High", and "Price: High to Low" to make informed purchasing decisions.
4.  **🔐 Secure Social Authentication:** Seamless and secure user login/registration system supporting Google, GitHub, and standard email methods, actively preventing duplicate account conflicts.
5.  **👤 Personalized User Profiles:** Logged-in users have access to a protected dashboard to view and update their profile details, complete with dynamic avatar rendering synced directly with their social accounts.
